# WinForms 软件说明书界面截图示意

## 概述

本技能用于在**无法截取真实软件界面**时，为 `.docx` 格式软件操作说明书生成并嵌入界面截图示意图。示意图从 WinForms 源码还原：标题栏、导航菜单、按钮标签、表格字段、状态栏、主题色等均与真实软件保持一致，便于新人阅读；后续可在有运行环境的机器上截取真实截图，按相同文件名替换后重新嵌入。

典型触发场景：
- 用户说“说明书里加几张界面截图”“纯文字看不懂”“新人不会操作”。
- 软件依赖 ET99 加密狗 / 授权 / Windows 桌面 / 特定 .NET Framework，当前沙箱无法启动。
- 真实截图尚未提供，需要先用示意图占位，后续再替换。

## 工作流判断

1. 检查当前环境是否能启动目标软件（是否存在可执行文件、依赖库、授权狗、桌面会话）。
2. 若**可以**运行：优先使用窗口截图工具或手动截图，再嵌入文档。
3. 若**无法**运行或用户同意先用示意图：进入“源码解析 → 绘制示意图 → 嵌入文档”流程。

## 步骤 1：解析 WinForms 源码提取 UI 规格

- 定位源码中的 `*.cs` 文件，重点阅读：
  - `FrmMain.cs` / `FrmLogin.cs`：窗口标题、尺寸、状态栏、退出按钮。
  - `UserControls/*.cs`：各功能页面布局（`Panel`、`SplitContainer`、`DataGridView`、`TreeView`、`FlowLayoutPanel`、`PictureBox` 等）。
  - `*Form.cs`：弹窗表单的字段与按钮。
- 记录以下信息：
  - 控件 Text（中文/英文标签）。
  - 颜色值：`BackColor`、`ForeColor`、`Button` 颜色（如 `49,53,59`、`24,144,255`、`76,175,80`）。
  - 尺寸与坐标：`Size`、`Location`、`Width`、`Height`。
  - DataGridView 列头、示例行数据。
  - 导航菜单项顺序、默认/激活项。

## 步骤 2：使用 Pillow 绘制界面示意图

- 创建 Python 脚本（参考 `scripts/gen_figures.py`），使用 Pillow 绘制 PNG：
  - 使用 Windows 自带中文字体（如 `C:/Windows/Fonts/msyh.ttc`、`simhei.ttf`）。
  - 复用一套 `app_shell()` 函数：标题栏、左侧导航、内容区、状态栏。
  - 为每个需要截图的界面编写独立的内容绘制函数，按源码颜色和布局绘制按钮、表格、卡片、表单等。
  - 输出按 `fig_X_Y.png` 命名，便于后续脚本按图号自动映射。
  - 在每张图右下角添加淡灰小字“示意 · 待替换为真实截图”，避免与真实截图混淆。
- 注意 Unicode 字形兼容性：避免使用字体不支持的符号（如 `✓`、`▾`），改用 `√`、`×`、绘制多边形箭头。

## 步骤 3：将图片嵌入 Word 占位符位置

- 在原始 `.docx` 中，占位符格式统一为：
  ```
  【图  <图号> <图题>  此处放置对应界面截图】
  ```
- 使用 `scripts/embed_images.py` 脚本：
  - 打开现有文档，正则匹配占位符段落。
  - 从占位符文本解析图号（如 `2-1`），映射到 `fig_2_1.png`。
  - 在占位符位置前插入居中的图片段落和“图 2-1 ...”图注段落，然后删除原占位符。
  - 图片宽度建议设置为 `Cm(15)`，让文档阅读时清晰可见。
- 验证：检查占位符数量是否归零、内联图片对象数量是否等于预期。

## 步骤 4：后续替换为真实截图

- 当获得真实截图后，将图片按相同文件名放入 `figures/` 目录。
- 重新运行嵌入脚本，或在 `python-docx` 中直接以同名图片覆盖关系（`document.part.related_parts[rid]`），即可完成替换。

## 资源

### `scripts/`

- `gen_figures.py`：从 WinForms 源码绘制界面示意图的模板脚本。包含通用窗体壳、按钮、表格、卡片等绘制函数，以及本项目中 12 张图的示例实现。新项目中需根据实际源码调整控件文本和布局。
- `embed_images.py`：读取 `.docx` 中“【图 ... 此处放置对应界面截图】”占位符，按图号插入对应 PNG 并添加图注。可复用于任何使用相同占位符格式的文档。

### 注意事项

- 示意图不是真实截图，应在文档中明确说明或保留“示意”字样。
- 若文档未使用统一占位符格式，需先调整占位符文本或修改嵌入脚本正则。
- 本技能依赖 `python-docx` 与 `Pillow`；请在隔离 Python 环境中安装（推荐 `--target` 或 venv）。
